# Commodore 1541 GCR fixtures

These deterministic fixtures are generated by:

```sh
python3 CORE/scripts/gen_gcr_fixtures.py --self-test
```

`gcr_nibble_codes.hex` contains the canonical 5-bit code for nibble values
0 through F. The header fixtures contain a track 18, sector 0 header with disk
ID `12 34`. The data fixtures contain one 256-byte sector generated by
`(index * 73 + 41) & 0xff`, wrapped with the data marker, XOR checksum, and two
padding bytes. Raw files have one byte per line; encoded files contain the
corresponding four-to-five GCR encoding, also one byte per line.

`gcr_geometry.json` records standard 35-track D64 and 70-track D71 sizes and
selected linear sector indices. Error-information trailers and extended-track
D64 variants are intentionally outside this fixture set.
