# Debugging virtual drives

The JTAG/QMON device, colour-coded LED overlay, and periodic Shell dumps used
during bring-up are **not in the bitstream**. Rebuild that pattern from
[jtag-debug-interface.md](jtag-debug-interface.md).

Current hardware status and remaining gaps are in [KNOWN_BUGS.md](KNOWN_BUGS.md).
Simulation gates are listed in [build-and-sim.md](build-and-sim.md).
